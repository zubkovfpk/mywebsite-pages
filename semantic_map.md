# Semantic Map: RU + International → сайт и нейминг

Сводка измеренного спроса (Wordstat API + Google Keyword Planner, 2026-11-18)
в рабочий словарь для копирайтинга, структуры страниц и проверки имён.
Источники: `research_wordstat_ru.md`, `research_keywords_intl.md`.

## Легенда

- **Спрос** — измеренный объём (корзины Wordstat / Google; порядок важнее точности).
- **Интент** — коммерческий (ищут исполнителя) / проблемный (боль) / информационный.
- **Шум** — доля нерелевантных запросов в кластере.
- **Периоды:** RU — скользящие ~30 дней (ноябрь 2026); intl — среднемесячное за 12 мес.
  Абсолютные числа между источниками напрямую не сравниваются — только структура и порядки.

## 3. Общая архитектура семантики

Три смысловых столпа, подтверждённых в обоих источниках:

1. **Оценить** (audit / аудит / readiness / оценка) — вход бюро.
2. **Разобраться с хаосом** (shadow AI / теневой ИИ / утечки / правила) — боль №1 после внедрения.
3. **Довести до масштаба** (pilot to production / пилоты→масштаб / сопровождение) — боль №2 и формат работы.

Поперечная ось: **контур/данные** (closed contour / on-prem / confidential) — ниша с нулевой конкуренцией в RU.

## 4. Импликации для нейминга

Спрос подтверждает семантические территории: **ясность** (audit, assessment),
**выбор** (ratio, eligo-семантика), **порядок/контур** (governance, context).
Проверка кандидатов на резонанс с измеренным спросом:

- **Контекст** — сильнее всего ложится на RU-семантику («контур», «контекст клиента»); риск — generic.
- **Ratio** — резонирует с audit/assessment/evidence; универсален для RU+EN.
- **ARC / GRID** — ближе к structure/framework-смыслам; поддерживают «бюро»-конструкторскую метафору.
- **Quaero** — «спрашиваю/исследую», ближе к readiness-фазе; слабее покрывает governance-половину спроса.

Имя ≠ SEO-ключ: ключевые слова — для дескриптора и подзаголовков
(«AI readiness & governance bureau» / «бюро обоснованного ИИ»),
не для самого бренда.
