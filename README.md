# Сергей Зубков — Fractional CAIO · Сайт (концепция B)

Экспресс-версия сайта: персона-лед «Экспертный кабинет». Принятая стратегия —
**B (ноябрь 2026, статика) → A «Вердикт» (product-led виджет) → C «Прозрачная фабрика»**.
Хостинг — **reg.ru** (см. `CONTENT_PLAN.md`, раздел «Деплой»).

## Как посмотреть прототип

Вариант 1 — просто открыть `index.html` в браузере.

Вариант 2 — локальный сервер (картинки/шрифты будут вести себя как в проде):

```bash
cd D:/WORK/AIprojects/mywebsite
python -m http.server 8123
# → http://127.0.0.1:8123
```

## Структура

```
index.html            — главная (все блоки концепции B)
assets/css/style.css  — дизайн-система (редакционная типографика, «бумага»)
assets/js/main.js     — шапка, мобильное меню, reveal-анимации
CONTENT_PLAN.md       — контент-план: страницы, тексты RU/EN, красные линии, SEO, деплой
```

## Дизайн-код

- Палитра: бумага `#FAF7F2`, чернила `#1C1B18`, акцент-зелёный `#0F5A46`;
  зонирование (зелёный/жёлтый/красный) — только в блоке вердиктов: отсылка к
  Autonomy Boundary Matrix, задел под концепцию A.
- Типографика: serif (Georgia-стек) для заголовков, system sans для текста,
  mono для «протокольных» подписей. Внешних шрифтов нет — осознанно (RU-доступность);
  в проде — self-hosted woff2.
- Движение — только функциональное (reveal, hover), с `prefers-reduced-motion`.
